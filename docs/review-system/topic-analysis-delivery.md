# 专题分析与图文报告交付

本轮按用户 2026-09-09 确认实施，跟踪 ChenShi-Tech/dljy#2875，父任务 #2033。

## 最终范围

按业务视角提供电量偏差、价格市场、历史比较、结算成本四专题；支持公司日周月与单笔对象、厂站/客户组合/项目及异常时段下钻。独立页面与居中弹窗共用分析组件。旧模板拆成分析因素，不再以模板清单组织工作。

异常按偏差与持续时间排序并可设门槛；日对上周同日，周月对上期，未结束周期按同进度。交易员补充数据和统一维护共用导入校验与批次版本。多个原因关联支持/反对证据，由人确认。

报告以图文块组织，一份底稿生成详版/管理层摘要。主笔编辑发布，同事批注参考；服务端保存、发布固定版本，网页/Word/PDF交付。AI辅助整理证据、局部改写与原因假设；人工保存发布不得依赖模型可用性。

## 当前实现（未合并上线）

- `src/components/review/workbench/TopicAnalysisPanel.vue`：电量/价格共用分时弹窗，基准切换、门槛、多时段框选/勾选、连续同向偏离分组、服务端统计、覆盖和口径展开。价格统计独立于电量；价差使用共同覆盖，均价同时显示各自有价时长。保存材料由服务器重算、持久化后交给底稿。
- `src/services/review/topicAnalysis.ts`：将当前复盘资料副本投影为带范围、时段、来源版本的预览输入，调用 `POST /api/v1/review/analysis/preview`。显式传递当前公司/租户，复用统一登录和地区头。客户端副本不等于认证真源或事前快照。
- 复盘中心新增“分时专题分析”，打开时固定资料副本，切换对象/公司/日期关闭旧上下文；统计失败不展示旧统计数，取消/乱序响应不覆盖新结果。
- `ReportWorkpaperEditor.vue`：服务器底稿目录、新建/读取/自动保存、图表/事实/原因/问题/措施、块移动与复制、支持/反对证据、管理层摘要、参考批注、主笔发布。慢请求不覆盖继续输入；版本冲突保留本地文字。关闭和离开页面提示未保存修改。新建不串入旧报告批注。
- `ReportEvidenceChart.vue` 和 `PublishedReportReader.vue`：读取冻结材料和已发布版本，区分价格/电量、缺测与不连续选区断线、资料来源提示，支持网页详版和摘要切换。
- `src/services/review/workpapers.ts`：底稿、材料、发布与批注客户端，显式固定公司/租户/地区头，不因全局切换把旧底稿写入新公司。主笔发布无需模型在线或同事审批。
- `src/composables/useEChart.ts`：增加实例创建回调，在延迟布局和主题重建后重新绑定选区事件。
- `reportPresentation.ts`、`reportWordExport.ts`：网页/导出共用图表配置和冻结材料，支持真正的 Word 文件（可编辑中文正文、嵌入图表、支持/反对证据、待核实状态）。详版与摘要均保留模拟/未认证性质；缺少被引用的图表材料时拒绝导出。`docx` 按需加载，依赖与锁文件同步；无外部数据上传和模型调用。API 用法核对 [docx Packer](https://docx.js.org/api/classes/Packer.html) 和 [ImageRun](https://docx.js.org/api/classes/ImageRun.html)。
