## 最终范围

按业务视角提供电量偏差、价格市场、历史比较、结算成本四专题；支持公司日周月与单笔对象、厂站/客户组合/项目及异常时段下钻。独立页面与居中弹窗共用分析组件。旧模板拆成分析因素，不再以模板清单组织工作。

异常按偏差与持续时间排序并可设门槛；日对上周同日，周月对上期，未结束周期按同进度。交易员补充数据和统一维护共用导入校验与批次版本。多个原因关联支持/反对证据，由人确认。

报告以图文块组织，一份底稿生成详版/管理层摘要。主笔编辑发布，同事批注参考；服务端保存、发布固定版本，网页/Word/PDF交付。AI辅助整理证据、局部改写与原因假设；人工保存发布不得依赖模型可用性。
