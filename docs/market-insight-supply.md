# 云南市场洞察供需与水电页（dljy#3008）

云南地区工作区 `/insight/supply` 页（`YunnanSupplyPage.vue`）的使用与口径说明。契约定义在后端仓（`dljy/shared/insight/`，经 `npm run sync:web` 镜像到本仓 `shared/insight/`，只读），本文只讲前端消费方式与守住的口径红线。

> 相关文档：[市场洞察数据口径说明](./market-insight.md)、[市场洞察公共证据组件与图表选区](./market-insight-common-components.md)、[云南市场洞察价格与价差页](./market-insight-prices.md)。

## 展示精简（dljy#3135）

电源非互斥、水电占比、区域周预测及预测对照等静态口径按需展开；云南/南网范围、未配对与数据缺失状态保持可见。 公共 `InsightNote` 使用原生 details/summary，默认收起且可用键盘展开。只调整展示，不改请求、计算、权限与保存行为。

## 交付边界

- **本页（任务 7.5/7.6）**：四页签——供需全景（含统计摘要与南网整体背景）、水电（含获权两区块）、预测与实际（forecast-error）、历史比较（剩余需求代理 + 窗口对比）。
- 页面已 `delivered: true` 进导航（`workspace.ts`）；其余五页（总览、价格、电网边界、场站、研究工作台）仍按各自交付状态，不受本页影响（prices 页三维热力未齐，仍为 false）。

## 分析目录

页顶固定三句口径：**市场阶段**（本页是系统运行数据，不是市场价格）、**区域**（云南与南网整体分开表达）、**原生粒度**（15 分钟；云南总送出预测 60 分钟）。

| 分析 | analysisId | 视图/入参 | 授权 |
| --- | --- | --- | --- |
| 系统曲线 | `supply.system-series` | `view: series / summary / forecast-error / residual-proxy`（31 天上限） | 公开 |
| 水电周出力 | `supply.hydro-weekly-output` | `objectIds`：区域多选（≤10），默认 `['云南']` | 获权 |
| 云南水电机组群 | `supply.hydro-unit-groups` | `objectIds`：机组群（≤50），默认未选 | 获权 |

- 系统曲线来源：云南口径的负荷 / 水电 / 新能源 / 非市场 / 总发电**实际**与负荷预测 / 新能源日前预测 / 非市场预测 / 云南总送出预测（60 分钟），以及南方电网整体口径（`csg-aggregate`）的同名背景曲线。
- 获权可见性按能力目录判定：公共账号不渲染获权区块、不发请求，只显示「获权数据需开通」；**不显示空框**。

## 四页签口径

每个页签懒加载（首次激活才查询），口径不变时切走再切回**不重查**；`series` 与 `summary` 两查询在全景与水电页签间共享（同键不重发）。

### 供需全景（series + summary）

- **云南主图不堆叠**：负荷、水电、新能源、非市场与总发电不是互斥分量，只叠线比较，不堆叠、不相加成「总供给」（页面固定文案 + 测试断言无 `stack` / `areaStyle`）。主图为 ChartCard 自绘：点集来自公共分组器（阶梯 `step:'end'`、缺测断开、边界点口径与明细图一致），**实际实线、预测虚线**，预测曲线有同图开关（默认关）。
- 序列名用**来源标题**（业务语言）：系统曲线无对象维度、字段无业务名，公共序列命名会退成「数据序列」，故借 `insightSourceTitle` 承载展示身份。
- 明细表（`InsightResultTable`）放在全景页签下方，随 series 结果。
- **南网整体口径是单独背景区块**（标题「南方电网整体口径（背景，不计入云南）」，默认折叠）：结果按 `businessScope === 'csg-aggregate'` 裁剪（序列、明细行、来源引用同步裁掉），不进云南主图、不计入云南任何汇总。
- 统计摘要卡：每序列一张（平均功率/最低/最高/有效时长，按登记精度，极值带出现时段）；**水电占比卡**单独成卡（`share:hydro:<scope>` 行），标题写清范围（云南 / 南方电网整体口径），卡片注明「同一业务范围内：水电 / 总发电（共同有效时段按时长加权）」。
- `notDerived` 与 `unavailableMetrics` 逐条**原文**展示（如「各类别相加的供给总量——不是互斥分量，不合成」「供电量 不可用：功率口径没有电量」），**不显示 0**。

### 水电（series 复用 + 获权两分析）

- 云南水电实际曲线（从 series 结果按类别裁剪）+ 水电占比卡（云南口径 share 行）。
- 固定说明「库容、来水、弃水等暂无来源，不展示」：无来源字段不放空图。
- **水电周出力预测（获权）**：区域多选**默认只选「云南」**，逐日平均出力（MW）按区域分列、不相加（云南与其他省不可加总）；未选区域不发请求。
- **云南水电机组群组成与占比（获权）**：选择机组群（数据基线当前只有「31 家水电」一群），表格列业务日 / 电厂 / 机组 / 出力占比（%）。上游数据集名称含「电量上限」，实际只披露组成与占比，**没有电量或出力上限值，不画上限线**（表格无「上限」列，页面说明原文）；未选机组群不发请求。

### 预测与实际（series + forecast-error）

- 预测选择器来自 forecast-error 目录的配对条目（`kind: 'forecast-error'`），标签按类别：负荷预测 / 新能源日前预测 / 非市场预测；默认第一个，切换是显式操作。
- **mode 固定说明**：「事后对照（只有发布日期，没有发布时刻，不能当事前回测）」——不是事前回测。新能源日前预测注明「按目标日对齐（发布日次日）」。
- 上下两图：原始曲线（预测虚线、实际实线，来自 series 视图、时间轴对齐）+ 误差曲线（值 = 预测 − 实际；合成序列借同范围实际来源承载展示身份）。
- 统计卡：MAE、平均偏差、共同/预测/实际有效时长（按登记精度）。
- **资格说明**：样本/覆盖率/门槛按后端数值陈述；未达门槛（样本 < 96 个 15 分钟点或覆盖 < 80%）固定显示「**可查看，不参与排名**」。
- `unpaired` 逐条显示原因（跨业务范围等不计算误差，名称用预测来源标题）；`notes` 与 `unavailableMetrics`（电量误差、MAPE）按原文展示，不显示 0。

### 历史比较（summary + residual-proxy）

- **剩余需求代理**：逐小时曲线（60 分钟）+ 统计卡（代理均值/最低/最高/共同时长）+ `formula` 与 `notes` 原文 + 固定说明「分析代理，不是官方竞价空间，也不是出清供需量」。**缺输入时不画空线**：`unavailable` 逐条显示原因（如「缺少输入：云南总送出预测这段日期没有资料」），item 映射为业务名。
- **窗口对比**：参考窗口**由用户显式选择**（默认不选、不自动选去年同期），未选不发请求。选定后对当前与参考窗口各查一次 summary（参考侧仍经请求代次机制，只覆盖 `businessWindow`），按**同一 seriesId 交集**并排显示平均功率/最低/最高，标签写清当前窗口与参考窗口的日期范围。
  - 只比较两边都有平均功率的序列（水电占比行没有平均功率，天然不进对比）；不同业务范围不互相比较（南网序列只与南网序列比，名称自带口径）。
  - 两个窗口天数不同时明示「平均值可比、合计不可比」。
  - **窗口变化后旧对比作废不显示**：迟到的参考结果经代次判定丢弃，不写进新状态。

## 页面状态纪律

- **前置拦截**：未选参考窗口、未选机组群、能力目录无获权分析，页面层直接不发请求（后端校验是第二道防线）。
- **口径签名**：查询键 = 查询名 + 上下文代次（日期窗/地区/公司）+ 各查询自身选择（区域 / 机组群 / 参考窗口）；上下文变化清空全部结果（含参考侧对比），局部选择变化只作废对应查询。
- **迟到作废**：所有查询经 `ctx.request.run`（代次机制），旧口径的迟到响应不写进新状态；失败也记键，同一口径下不自动反复重试。
- **历史候选**：「查看可分析日期」按云南五条**实际**来源求交集（`requiredSourceIds`；南网背景与预测来源不参与），候选只经用户点击生效。
- 不缓存任何私有结果（获权数据零落盘），切地区或公司由上下文代次统一作废。
