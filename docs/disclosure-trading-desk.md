## 阅读流程

页面服务日前、日内交易的通用市场观察。桌面左侧是趋势、披露轨道、六类主题和信息卡；右侧是与当前地区、日期、选区一致的事实摘要、证据和标注。参考 PokieTicker 的时间选取与信息联动，不引入股票收益、涨跌概率或自动 AI 判断。

1. 默认当前地区、今日，选择单日或近七日。今日无数据时明确提示，点击最近可用日才进入历史数据回看。
2. 默认看日前/实时用户侧统一电价，价差统一为“实时－日前”，六个主题均未选中，下方为“全部披露”。通过主题切换负荷、新能源水电、备用调峰、检修停运、输电断面、市场干预；再次点击已选主题取消选择，恢复价格主图和全部披露。交易日期与已选时段保持，清除主题附带类别和旧事件详情。事件圆点等定位操作仍明确进入对应主题，不因已选中该主题而取消。
3. 悬停只作临时预览；单击曲线区域选中一个原始时段，按住鼠标左键水平拖动选择多个时段，松开后联动卡片和摘要。拖动中仅预览选区，不重新查询列表；支持反向拖动。点击画布边缘、空白轨道或标题旁留白取消时段选择；图例、事件圆点和控件不触发清空，拖动结束的后续点击也不误清选区。图表不再提供框选开关或 ECharts 框选工具栏。
4. 关联披露默认按电厂/对象分组并收起，组标题显示名称、匹配条数和类别。点击组标题展开各条原始披露，组内独立分页；也可切换紧凑列表或信息卡片。每条并排展示对象、类别、时间口径、起止日期和已知总时长。检修停运使用停电/复电名称，其余类别使用生效/结束名称。缺失时显示“未提供”，仅有干预时刻的记录显示“已知时点”。点击记录查看右侧证据和个人/公司标注；关闭详情保持分组展开、组内页码及筛选。关键词、类别与所选主题参与事件查询；翻页不改变全量统计。
5. 指标披露按指标/日期汇总，不把每个采样点伪装成一条消息。通道型数据自动选中当前日期有有效样本的明确对象，优先保留本公司本地区下手动选过的对象，其次当前省份，再按名称稳定选择首个可用对象；选择器始终显示对象名称，可手动切换。没有有效对象时保持缺数提示，不换日期或拼接其他对象。
6. 右栏“披露较多时段”按当前筛选下相关记录数排序，最多展示两个时段，点击后筛选列表；单日按小时、近七日按日统计。跨时段记录可重复计数，数量不表示影响程度。右栏不再展示“开始依据字段”“结束依据字段”和“数据边界”区块。
7. 新指标放在原有六类主题内，通过主题内子指标按钮或按主题分组的指标选择器切换。主图选择器采用可搜索的主题菜单，输入指标名称筛选，当前项以主题色和勾选标记显示；支持方向键、Enter 选择及 Escape 收起，点击控件不清空原选区。“联络线与断面”的主题数字是事件披露数量，不是曲线数量。主图根据当前指标自动选择明确联络线、关键通道、线路/变压器、断面或送电类别；单个有效候选直接显示。容量、稳定断面负载率、优先送电电量下限等日级数据仍用数值卡展示；调峰需求等文字事项直接展示当日原文，不显示为空曲线。
8. “备用与调峰”内提供必开必停日级名单，可按状态、关键词和变化筛选、分页并展开来源。变化比较使用上一真实可用日，界面明确比较日期，不把它称为自然日“昨日”。同机组出现矛盾状态时保留双方并标记冲突，停止该对象的变化判断；名单缺失或不完整时不推算新增、移除。
9. 右栏“当期关键变化”随选区变为“选区关键变化”，显示有效样本内的最大有符号价差、最大绝对预测偏差以及负荷/新能源最大的连续 15 分钟变化。点击条目定位原始指标与时段；更换选区复用已加载样本，切换日期、地区、公司或刷新才重新读取。

## 全部披露与检修停运整理

未选择任何主题时提供对象名称、原因/摘要搜索，以及全部五类事件按钮、时间关系、排序和紧凑列表/信息卡片切换。通用时间条件显示“窗口内开始”“窗口内结束”“贯穿所选窗口”“时间不完整”；排序按开始、结束或已知总时长，不将人工干预和输电约束的时间写作停复电。全部披露与检修视图保留同一组局部搜索和整理条件；切到其他主题时暂停这些条件，取消主题后恢复。局部“清空筛选”保留顶部关键词、交易日期和时段，页头“重置筛选”恢复完整默认查询。

设备/电厂搜索只匹配对象名称；原因/摘要搜索匹配来源摘要。两项可叠加，260 毫秒防抖后与顶部关键词共同提交。专业筛选包括检修计划/非计划停运，以及相对当前交易日或图上选区的时间关系：窗口内开始停电、窗口内复电、贯穿所选窗口、时间不完整。切换时间关系保留当前选区，清空专业筛选保留交易日和时段；切换地区或公司清空专业筛选和失效详情。

列表与主题数量、右栏统计共用服务端全量筛选；按停电时间、复电时间或已知总时长排序，未知时间置后，稳定事件 ID 保证分页顺序。只有完整且合法的起止时间参与覆盖窗口或总时长计算；没有复电时间不推定持续生效，源记录入库时间不参与这些筛选。时间不完整模式保留查询业务日内时间异常记录，也不把“发布时间未知”当作停复电异常。排序只重取列表，悬停不发请求，图上选区则同步列表、统计与摘要。

## 披露圆点与时段选择

事件轨道独立读取完整交易日期范围、全部类别的服务端聚合，保留地区、公司和顶部关键词条件。选择时段、主题、类别或检修专业筛选不会隐藏其他时段、类别的圆点，也不会重取轨道；下方列表、主题数量与右栏仍按选区和专业筛选更新。轨道与选区统计分别隔离在途请求，切换日期、地区或公司时清除旧结果，旧响应不覆盖新上下文。

有有效时刻的记录按小时或日期分桶；同一跨时段事件可以出现在多个桶，不能将各桶相加当作独立事件数。点击圆点切换对应主题、类别并锁定该桶的原始区间，不按当前曲线粒度重新取整；同时清空检修专业筛选，避免列表与所点圆点的范围不一致。

图表下方直接衔接主题分类；不显示日级记录分类入口、轨道说明、类别释义、操作提示、日级汇总条或覆盖与查询数量栏。仅有业务日期的记录仍按业务日纳入全天列表，不放到任意小时、不推定持续生效。没有对应时间数据的类别不生成小时圆点。

## 按电厂和对象归组

分组来自 `GET /api/v1/grid/geo-assets/disclosures/groups` 对完整筛选范围的聚合，每页 12 组。每组计数和类别数量包含匹配的全部记录，不由当前页推算。展开后使用同一筛选及不透明 `groupKey` 精确读取组内记录，每页 8 条；收起再展开复用当前页，切换日期、地区、公司、筛选、排序或刷新则重新查询并隔离旧响应。

来源已明确的电厂名称、南网披露编译器标题中明确的电厂/厂站名称可用于归组，同一厂的不同机组和类别放在一起。未确认电厂归属的线路、设备、断面按完整对象名称分组；未知对象，以及仅提供 #2F、5002DK、1号机等编号而缺少厂站依据的记录，保持独立，不通过相似字词猜测所属电厂。同名对象按发布方和地区隔离：南网整年导出（2026-07-02 及之前）与日文件接续（2026-07-03 起）同属南网发布方，同一设备或电厂跨 07-02/07-03 归为同一组（后端 dljy#3517）；来源名只作溯源显示，信息卡片按事件自己的来源显示名称，来源未登记时显示「来源名称待确认（来源 ID）」（dljy#3563）。归组只改变阅读结构，不合并删除源事件，不修改收藏和笔记身份。

默认按记录数排序，再按名称与稳定组标识排序；选择开始、结束或已知总时长排序时，分别按组内最早有效开始、最早有效结束或最长有效时长排列。组内采用相应单条排序。紧凑列表与信息卡片互切不重新取数；分组与逐条模式互切回到对应第 1 页。单事件圆点可自动展开唯一匹配组并打开该条详情。

对象候选和曲线从同次日期数据构造，自动回填选择不会再次请求原始数据。主图、选区摘要和主题覆盖共用最多 30 秒的有界缓存与在途请求合并，按地区、公司、刷新代次、数据集和日期隔离；错误、无权限、模拟、截断或地区不匹配的响应不留存。手动刷新绕过旧代缓存。主图不再为已移除的底部覆盖栏单独读取覆盖元数据。

公开指标的 ISO 日请求由后端按原业务日期在 PG 提前切片，不再先把整年 payload 拉到 Node 再过滤；`_filter.total` 保留完整数据集行数，真实空日、尾部截断、D-1 与地区/公司读取约束仍按原契约处理。接口细节和数据库专项验收见后端披露域说明。

两个公开大族的覆盖查询改用现有索引读取真实计数、空日期数量及日期首末值，避免全量分组的磁盘排序；目录只用于枚举 RLS 可见数据集，不用目录行数代替真实行数，也不新增后端覆盖缓存。空日期、空字符串、来源和公司/地区权限结果与旧查询逐项对拍。

## 新增指标与名单

本批沿用现有数据源与主题，不增加中优先级指标或自动交易判断。

| 主题 | 指标标识 / 名称 | 展示与数据口径 |
| --- | --- | --- |
| 负荷与供需 | `non-market` / 非市场化电源出力 | `yn_system_forecast/non_market_forecast` 与 `non_market_actual`，MW、15 分钟；分别展示预测和实际，仅同省域、同指标与同单位样本计算“实际－预测”。不把全网行混入省级偏差。 |
| 联络线与断面 | `key-channel` / 关键通道实际输电 | `yn_disclosure_metric/actual_key_channel_transmission`，MW、15 分钟；先选明确通道，再展示对应曲线。 |
| 联络线与断面 | `key-line-transformer` / 关键线路与变压器实际潮流 | `yn_disclosure_metric/actual_key_line_transformer_flow`，MW、15 分钟；不同线路或变压器保持独立。 |
| 联络线与断面 | `section-constraint` / 输电断面双向限值 | `yn_disclosure_metric/actual_transmission_section_constraint`，MW、15 分钟；同一选中断面的“正向限值”“反向限值”分成两条曲线，保留原始符号，不给反向值自动加负号。 |
| 联络线与断面 | `interprov-forecast` / 省间送受电预测 | `yn_system_forecast/inter_provincial_forecast`，MW、1 小时；`region` 在此源中是断面名称，送电与受电由两个独立 `metric` 区分。明确选择源断面后，仅展示该对象实际披露方向的小时阶梯预测线；未披露相反方向不记作缺测，已披露方向中的空值仍留空，不合计不同断面。 |
| 联络线与断面 | `priority-limit` / 省间优先送电电量下限 | `yn_disclosure_metric/forecast_interprov_priority_limit`，MWh、日级；先选送电类别，每日一个数值并展示限值原因、业务日期与来源文件。原文原因是空值或“空”时显示“未提供”。 |
| 备用与调峰 | 必开必停名单 | 日级机组清单保留状态、原因和来源；按上一真实可用日比较变化，提供冲突和覆盖情况，不把名单状态编码成连续功率。 |

96 点源保持每日 96 个原始时槽；按指标/日期汇总成卡。同一数据集中的双方向或送受电曲线共用一次日期分片请求。源记录没有省份或坐标时，保留南网范围与对象名称，不按名称推断省域位置。

断面限值、实际潮流、送受电预测和优先电量分别展示。未证明同地区、同对象、同方向和同时间口径时，不计算限值裕度；日级 MWh 下限也不能与分时 MW 潮流直接相减。同对象同日/时槽存在冲突值时留空待核验，不按接口返回顺序取最后一条。

右栏摘要的比较规则：价差按“实时－日前”的**有符号数值**取最大值；负荷、新能源、非市场化电源的偏差按**绝对值**寻找最大偏差，显示的仍是带符号“实际－预测”。连续 15 分钟变化只比较相邻且都有效的负荷/新能源采样，预测与实际分别计算后显示绝对变化最大的序列，并标明序列名称。缺测、非连续时点、小时或日级值不参与这项计算；选区外的前值不会带入。仅比较与选区重叠的原生时段，点击后定位这些原始时段。读取失败、无权限或缺少可比较样本时明确说明，不从残留数据生成摘要。

## 数据口径

- 价格、供需和数值披露继续使用 `/api/real`；`yn_system_forecast`、`yn_disclosure_metric` 为当前接入族。不是新增实时采集器，所选日期与缺数状态仍在主图上下文显示。覆盖服务 `/api/real-coverage` 保留供其他数据链使用。
- 单位和粒度读取共享指标目录。小时价格和省间送受电预测保持阶梯，15 分钟功率保持原粒度；真实零值保留，缺测断线，不插值或补零。日级值以数值卡呈现，不能扩展为全天连续曲线。
- 新能源 D-1 按 `targetDate` 对齐；不得把全部预测都视为前一日已发布。预测/实际只有地区、指标、时间口径一致才计算偏差。南网总发电预测不与云南总发电实际计算偏差。
- 业务日期、有效时间、公开发布时间、源导入时间和编译时间不同。源未给发布时间则显示未提供；历史回看不能冒充当时已知信息回放。
- 事件来源与许可、原记录 ID 可追溯。无原文 URL 不生成链接，无坐标仅展示省域/全网范围或断面名称。
- 全量聚合来自 `/api/v1/grid/geo-assets/disclosures/overview`，事件分页、详情和版本化标注沿用同一前缀。公司/地区切换丢弃旧响应；公司标注仍受原角色权限控制。
- `yn_disclosure_metric` 使用已有公开导出 CSV 的归一化与 capture 数据链，不依赖公司私有节点价或私有接口。后端 `scripts/etl/import-disclosure-metrics.mjs` 按预检结果补入页面所需数据，不修改原始 CSV。接口明确报告该 family 未接入的 404 显示“尚未接入”，明确无采集文件显示缺数，权限错误与其他 404/500/网络异常仍分别显示无权限或读取失败，不用重试提示掩盖未接入。
- 检修与停运使用已确认的停电—复电区间与用户选区重叠匹配，包括开始早于选区或跨日的记录，不以源记录入库时间过滤。完整、合法的实际停复电优先；计划停复电作为独立成对依据，不能混用实际开始和计划结束。没有复电时刻的记录不推定持续到全天或未来。详情显示实际/计划等时间依据，源字段名仍保存在数据中但不展示；切换主题保留所选时段。

**模式**：默认“真实日前”，目标日为北京时间次日，只读展示。可切到“历史资料审阅”并选择日期；预填为页面选区末日（近七日视图即窗口末日），但必须点击“开始研判”才运行，打开弹窗不会自动运行。结果区的模式标识常驻：真实日前显示“真实日前”，审阅显示“历史资料审阅，非当时已知回放”，不可折叠或隐藏。

**状态**：依次区分读取功能状态中、功能未开通（`enabled:false`，不提供运行入口）、地区不支持（非云南直接显示，不请求、不回读云南）、模型未配置（仍可运行，提示停运原因不做研判）、明日资料未到（目标日的检修计划与必开必停名单都未收到：保持目标日，只提供“改为历史资料审阅”的显式按钮，不自动跳日、不自动运行）、运行中、仍在运行（轮询 60 秒未完成，可“继续查看”）、请求失败（错误码转中文）以及结果。接口返回只有运行头（进行中，或失败/中断且无结果）时，只显示状态与错误，不显示事项。

**请求口径**：`GET /watch-capabilities?tradeDate=`、`POST /watch-runs`（请求体只有 `{tradeDate, mode}`，带 `Idempotency-Key`）、`GET /watch-runs/:runId`、`POST /watch-runs/:runId/feedback`，前缀与现有披露接口相同。每次请求显式携带发起时的地区头和 `?company=`。一次点击生成一个幂等键；网络或服务端 5xx 失败后“重试”沿用同一个键，拿到终态或业务拒绝（409/422/428 等）后再发起则换新键。HTTP 202 表示仍在运行，每 2 秒查询一次，最长 60 秒。公司、地区、目标日或模式变化会中止在途请求，并按代次丢弃旧响应，旧结果不会写进新界面。模型提供方鉴权失败由后端放在结果 `errors[]` 中，不返回 HTTP 401，前端不改全局登出逻辑。

**结果呈现**：
