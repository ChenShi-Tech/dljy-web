# 当日披露总览组件说明

这个页面对应预测中心里的“多目标总览”新实现，但它展示的是“已导入的官方披露数据”，不是平台现场去调用模型推理。

## 曲线看板更新（2026-08-31）

- 数值曲线排在检修文本之前，图表内部也把长来源说明移至图下“来源与口径”。使用现有白底、青绿、6px圆角和字号变量，未重做站点设计。
- 所有有有效点的序列独立为卡片；云南省内/南网全网/跨省断面、供需不同指标均可单独选择。06-25/26真实数据共13数据集、25曲线；未预置固定25个空框。
- 点击“选择展示曲线”展开按类别排列的复选框，“显示全部曲线”和“清空选择”适用全部曲线。搜索仅筛选可见内容，不改变已勾选状态。
- `src/services/forecast/disclosureDashboard.ts`（曲线拆分助手）保留原始点值、缺口、目标日、单位和原始行，仅把每卡series收窄为一条。选择键按数据集/范围/指标/单位/相对预测跨度构成，换日可记忆、同日D+1/D+2可独立勾选。
- 偏好仅在本地保存隐藏曲线键，不缓存数据值；地区/公司分开，存储失败仍可操作。切地区/公司/日期会丢弃在途旧请求。
- 全部取消、搜索无匹配、无当日数据、存在原始行但不能安全绘图分别提示，原始行仍可展开核查；不新增占位模型或曲线。
- `DisclosureDatasetCard.lifecycle.component.spec.ts`保留真实useEChart，仅替换绘图库边界，测试初次挂载、零尺寸转可见、无图转有效点、卸载释放。此类测试不是浏览器像素验收。
- 新获用户授权后IAB实际重试5174仍被保存的权限拒绝；没有改用其他浏览器或命令绕过，最终视觉验收未完成。

展示层由两个组件组成，取数和页面接入单独分层：

- `src/components/forecast/DailyDisclosureOverview.vue`：总览容器。负责按日期/地区读取 13 个已接数据集、分 4 个分组展示、搜索过滤、失败提示，以及底部“数据覆盖清单”。
- `src/components/forecast/DisclosureDatasetCard.vue`：图表卡片。看板传入单条曲线和独立标题；其他调用仍兼容同数据集“同范围 + 同目标日 + 同单位”分组及范围切换，明细保持源数据集当日全部原始行。
- `src/services/forecast/dailyDisclosure.ts`：读取真实披露、校验来源和地区、按原生时间粒度整理曲线；最多3路并发，不调用模型。
- `src/views/forecast/ForecastWorkbenchView.vue`：只在打开云南“多目标总览”后挂载，避免单算法页面额外读取13集。顶部日期改为源记录日期，隐藏不适用于披露回放的训练窗口等控件。

关键设计约束：

- 只展示已经接入的 13 个云南公开披露数据集，不假装展示“官方所有数据”。
- 日期按源记录日读取；新能源等预测数据如果目标日是 `D+1`，会明确标出来，不会回退一天冒充当天。
- 结算价属于“披露/实际价格”，不是模型预测，不会额外加价格预测线。
- 非价格功率类字段目前统一按“原始值”展示，因为旧目录和适配器文档的单位定义冲突；组件只提示风险，不擅自做 `×0.1` 之类缩放。
- 空日期、非云南地区、当日无数据、部分失败都要如实提示；不会渲染 13 个空占位图框。
- 日期或地区切换时会立即作废在途请求，避免 A→B→A 场景下旧结果回写新页面。
- 有原始记录但无可绘制点时保留明细入口，不画空图。明细包含当日全部统计范围及字段，数值不再次四舍五入；空值不补零。
- 采集/导入时间不是业务数据截止日，也不代表官方精确发布时间。记录日与预测目标日分别标明。
- 按容器宽度显示1/2/3列（价格最多2列），同列等宽、图底对齐；标题单行省略并保留完整title。白底细边框、6px圆角和现有主题字号沿用设计参考。
- 图表在DOM更新后绘制；重载/搜索前清理非响应式图表引用，避免刷新循环和失效实例累积。

覆盖清单的含义：

- “数据集”是已经接入的源表，不是模型数。
- “数据性质”只区分价格、预测、实际、供需。
- “统计范围”来自源记录里的范围字段，可能是云南省内、南网全网或跨省断面。
- “目标日”只在源记录明确给出 `targetDate` 时显示；否则展示“仅记录日”。
- “有效时段”显示每条曲线的 `有效点数/理论点数`，不是训练样本量。

组件没有做的事：

- 不触发本地模型或南洋推理服务。
- 不改父页面地区上下文。
- 不把失败数据偷偷回退成模拟值。
