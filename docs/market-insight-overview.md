# 云南市场洞察市场总览页（dljy#3009）

`/insight/overview` 的云南实现（OpenSpec build-yunnan-regional-market-insight 任务 8.3/8.4，规格 `yunnan-market-overview`）。本文记录页面结构、区块口径与页面状态纪律；数据契约见 dljy 仓 `docs/api/market-insight-contract.md`。

## 页面结构

区块清单来自共享契约 `shared/insight/overview.mjs` 的 `OVERVIEW_BLOCKS`：每个区块就是某个已登记分析的某个视图，页面逐块独立查询、独立重试，一个来源失败只影响它自己的区块（OV02）。总览不另写一套口径，任何数值都出自后端已登记视图，本页只呈现、不计算。

| 区块 | 分析 / 视图 | 内容 | 下钻 |
| --- | --- | --- | --- |
| 重点事项 | `overview.key-items` / `key-items` | 最多五条可证重点 + 每条规则的评估状态 + 负荷同进度比较 | 按事项自带的 drilldown 解析目标页 |
| 价格概况 | `prices.user-series` / `summary` | 用户侧日前/实时：时长加权均价、最低/最高、负价时长、有效小时 | 价格与价差页 |
| 日前实时价差 | `prices.user-series` / `spread` | 共同覆盖配对：价差均值/绝对均值/极值/正价占比 + 异常时段表（前五条） | 价格与价差页 |
| 供需与水电概况 | `supply.system-series` / `summary` | 云南实际序列（负荷/水电/新能源/非市场/总发电）均值与极值 + 水电占比 | 供需与水电页 |
| 预测与实际 | `supply.system-series` / `forecast-error` | 配对 MAE/偏差/共同时长 + 资格说明（事后对照） | 供需与水电页 |
| 跨省与电网边界 | `grid.boundary-series` / `series` | 公开披露背景曲线 | 跨省与电网边界页（建设中） |
| 获权场站表现 | `plants.settlement-daily` / `series` | 场站日结算明细（按能力目录判定可见） | 场站市场表现页（建设中） |

## 口径要点

- **默认当日**：进页面自动加载当日事实，不需要预检点击；默认窗口是北京时间当日，不自动改日、不自动跳「最近有数据的日子」。当日缺数由各区块的可用性说明与「查看可分析日期」候选入口表达（A02）。
- **不混五月与八月**：历史候选按区块所属分析的必需输入求交集（供需概况按云南 5 条实际来源、预测按负荷/新能源的预测+实际、key-items 按全部输入），用户选择候选后才改窗口（A22）。
- **重点事项不凑数**（OV03）：最多五条、无满足条件就少于五条；阈值是平台分析默认值，不是官方规则；每条事项只陈述观测与阈值，不下因果；「为什么没有这一条」由规则评估逐条展示（含数据不足/不适用的原因原文）。
- **同进度比较不造假环比**（OV04）：只对单日窗口做；前一日同时段不完整时只说明原因，本期值在供需区块查看。
- **下钻带同一业务日期**（OV05）：区块按钮与事项「查看详情」都 `router.push` 规范地址（`/insight/<pageId>`）并携带 `start`/`end`；未交付页由工作区宿主渲染「正在建设」占位，本页只标注、不伪造入口能力。
- **获权区块按能力目录判定**：公共账号不渲染获权场站区块、不发获权请求，不显示空框。
- **天气等旧驾驶舱大块不带入本页**：收拢为各详情页自己的事。

## 页面状态纪律

- 能力目录失败：顶部告警 + 重试，不影响已就绪区块。
- 单区块失败：该区块独立错误态与重试，其他区块照常。
- 窗口/地区/公司变化：上下文代次 +1，所有区块旧结果作废、全部重查；迟到响应不写入新状态。
- 查询签名去重：同口径下有结果或已失败过的区块不自动重查，重试由用户触发。
- 界面只用业务语言（来源标题来自能力目录），不出现来源标识、family 或 SQL 原文。
