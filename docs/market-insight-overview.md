# 云南市场洞察市场总览页（dljy#3009）

`/insight/overview` 的云南实现（OpenSpec build-yunnan-regional-market-insight 任务 8.3/8.4、10.7，规格 `yunnan-market-overview`）。本文记录页面结构、区块口径与页面状态纪律；数据契约见 dljy 仓 `docs/api/market-insight-contract.md`。

## 页面结构

区块清单来自共享契约 `shared/insight/overview.mjs` 的 `OVERVIEW_BLOCKS`：每个区块就是某个已登记分析的某个视图，页面逐块独立查询、独立重试，一个来源失败只影响它自己的区块（OV02）。总览不另写一套口径，任何数值都出自后端已登记视图，本页只呈现、不计算。

2026-09-20 视觉修订（dljy#3135）：首屏为市场价格与重点关注，后续为供需与水电、预测偏差、价差、跨省送受趋势、电网动态及场站表现。桌面采用 12 列网格，市场指标占 8 列、重点关注占 4 列；窄屏逐步切换为单列。

| 区块 | 分析 / 视图 | 默认展示 | 下钻 |
| --- | --- | --- | --- |
| 市场价格 | `prices.user-series` / `summary` | 日前/实时均价大字、最低至最高区间与均值标记、负价时长与有效小时 | 价格与价差 |
| 重点关注 | `overview.key-items` / `key-items` | 最多五条观测与负荷同进度比较；基准、覆盖、规则按需展开 | 事项对应详情 |
| 供需与水电 | `supply.system-series` / `summary` | 云南实际均值、极值区间、水电占比 | 供需与水电 |
| 预测偏差 · 事后对照 | `supply.system-series` / `forecast-error` | MAE/偏差/共同时长与资格 | 供需与水电 |
| 日前实时价差 | `prices.user-series` / `spread` | 价差均值、极值区间；异常时段表折叠 | 价格与价差 |
| 跨省送受趋势 | `grid.boundary-series` / `series` | 既有披露曲线 | 跨省与电网边界 |
| 电网动态 | grid-geo overview/events | 原始/独立事件计数、计划/实际分组、近期事件时间线 | 检修与干预 |
| 场站表现 | `plants.settlement-daily` / `series` | 获权日结明细 | 场站市场表现 |

区间条仅编码服务端已返回的最低、最高和均值，不代表时间走势；缺值、倒置区间不画条，恒定值居中。`OverviewMetricCard` 保留全部指标与极值出现时间在「指标明细」中，不改统计精度或计价口径。来源清单折叠为数量和公开/获权标记，证据入口独立可用。

## 电网事件摘要（dljy#3102，任务 10.7，GB04 + OV02/OV03）

总览的「电网事件摘要」区块置于跨省送受趋势之后，与电网边界页检修干预页签（10.6）消费**同一批** grid-geo 披露事件接口（`/disclosures/overview` + `/disclosures/events`，`identity=annotate`），不重建事件事实库、不经洞察分析查询：

- **计数与归并口径（GB04）**：窗口内原始记录数、独立事件数与身份不足未归并数来自后端 identity 归并汇总；计划（maintenance，检修计划与电网检修信息）与实际（intervention+outage，人工干预与非计划停运）分组与电网边界页一致。后端未返回归并汇总（旧版读模型）时只显示原始数并如实说明「身份归并结果未提供」，不硬凑独立事件数。
- **最近 3 条**：窗口内停电时间最晚的三条记录，展示标题、类别与时间口径状态（计划区间/实际区间/仅业务日期/未提供）、起止（缺失如实「未提供」）与重复披露版本标注；明细记录超过一页时取末页尾部。
- **下钻**：携带当前业务窗口（query `start`/`end`）跳电网边界页检修干预页签；检修干预页签由该页承载，本页不重复实现明细表。
- **同口径说明**：区块内「事件统计口径」可展开查看「摘要与电网边界页完整筛选同源同口径；导出不等于当前页，明细以电网边界页为准」——本区块不提供导出入口（洞察导出只覆盖分析区块，披露摘要不伪造全量口径）。
- **诚实空态（OV03）**：事件源未接入（`not-configured`）、窗口内无已导入记录（`missing`）或记录数为 0 时，区块显示空态与后端原因原文，不渲染计数卡与最近列表、不硬凑卡片。
- **可见性按接口实际语义**：披露事件是公开披露数据的公司级作用域读取，不按洞察能力目录门控（公共账号可读摘要）；未选公司、地区不符或服务端拒绝时诚实报错并可重试。
- **独立查询与隔离（OV02）**：本区块独立于能力目录与洞察查询管道，独立加载/错误/重试；明细（最近三条）失败只影响明细段，已就绪的计数照常展示；窗口/地区/公司变化（上下文代次）时独立作废重查。

## 口径要点

- **默认当日**：进页面自动加载当日事实，不需要预检点击；默认窗口是北京时间当日，不自动改日、不自动跳「最近有数据的日子」。当日缺数由各区块的可用性说明与「查看可分析日期」候选入口表达（A02）。
- **不混五月与八月**：历史候选按区块所属分析的必需输入求交集（供需概况按云南 5 条实际来源、预测按负荷/新能源的预测+实际、key-items 按全部输入），用户选择候选后才改窗口（A22）。
- **重点事项不凑数**（OV03）：最多五条、无满足条件就少于五条；阈值是平台分析默认值，不是官方规则；每条事项只陈述观测与阈值，不下因果；「为什么没有这一条」由规则评估逐条展示（含数据不足/不适用的原因原文）。
- **同进度比较不造假环比**（OV04）：只对单日窗口做；前一日同时段不完整时只说明原因，本期值在供需区块查看。
- **下钻带同一业务日期**（OV05）：区块按钮与事项「查看详情」都 `router.push` 规范地址（`/insight/<pageId>`）并携带 `start`/`end`；电网与场站详情页已经交付，不再显示旧的「正在建设」说明。
- **获权区块按能力目录判定**：公共账号不渲染获权场站区块、不发获权请求，不显示空框。
- **天气等旧驾驶舱大块不带入本页**：收拢为各详情页自己的事。
- **电网事件摘要不重建事实库**（10.7）：与电网边界页检修干预页签同一批披露事件接口、同一归并口径；导出不等于当前页，明细以电网边界页为准。

## 页面状态纪律

- 能力目录失败：顶部告警 + 重试，不影响已就绪区块。
- 单区块失败：该区块独立错误态与重试，其他区块照常。
- 窗口/地区/公司变化：上下文代次 +1，所有区块旧结果作废、全部重查；迟到响应不写入新状态。
- 查询签名去重：同口径下有结果或已失败过的区块不自动重查，重试由用户触发。
- 界面只用业务语言（来源标题来自能力目录），不出现来源标识、family 或 SQL 原文。

## 视觉修订验收（dljy#3135）

- 以独立、显式标注「模拟数据」且不连接业务接口的临时组件夹具检查指标卡、总览网格与原生折叠交互；1440px 宽屏、390px 窄屏以及 default/arc 主题均已检查，窄屏无横向溢出。夹具不进入产品或仓库。
- 真实业务实例预览运行于本次工作树的 5175。内置浏览器尚未登录，Chrome 连接不可用；本记录不将组件夹具等同真实六页端到端验收。
- 数值、空态、获权隔离、独立失败、下钻与六页请求由既有组件回归验证；新增区间用例覆盖负值、缺值、倒置与恒定区间。
